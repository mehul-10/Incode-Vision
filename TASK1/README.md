# 🤖 AI Chatbot

A simple NLP-powered AI chatbot built as part of the **IncodeVision Artificial Intelligence Internship**.

The chatbot accepts natural-language user messages, identifies the user's intent using a combination of conversational matching, keyword detection, TF-IDF vectorization, and cosine similarity, and generates an appropriate response.

---

## ✨ Features

- 💬 Interactive chatbot interface
- 🧠 NLP-based intent detection
- 🔤 Text preprocessing
- 📊 TF-IDF vectorization
- 📐 Cosine similarity
- 🎯 Intent classification
- 🛡️ Confidence threshold and fallback handling
- 💡 Suggested questions
- 🧹 Clear chat functionality
- 🔍 Intent and match-score analysis
- 🌙 Responsive dark-themed interface
